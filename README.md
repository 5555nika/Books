
# 📚 BookFlow — Personal Library Manager

🚀 **Live Demo:** [https://books-pi-gray.vercel.app](https://books-pi-gray.vercel.app)

A modern, responsive book management application built with **React**, **TypeScript**, and **Ant Design**.

---

## ? Features

- ?? **Full CRUD:** Add, view, edit (via modal), and delete books with confirmation dialogs (Popconfirm).
- ?? **Live Search & Filters:** Instant search by title or author, filter by language (English, Turkish, Russian).
- ?? **Real-time Statistics:** Track total books, page count, and language variety.
- ?? **State Persistence:** Local storage synchronization for persistent data between sessions.
- ?? **Export Data:** Download your library catalog as a formatted JSON file.
- ?? **Unit Tested:** Comprehensive test coverage using **Vitest** and **React Testing Library**.
- ?? **CI/CD:** Automated build and deployment pipeline via **Vercel**.

---

## ??? Tech Stack

- **Frontend:** React 19, TypeScript, Ant Design 6
- **Routing:** React Router v7
- **Testing:** Vitest, React Testing Library, jsdom
- **Build & CI/CD:** Vite, Vercel
